          First-time setup (~3 minutes)
          1. Cloudflare Dashboard → your Pages project → Settings → Functions.
          2. KV namespace bindings → Add binding:
            • Variable name: PORTFOLIO_KV
            • KV namespace: click Create new → name it portfolio-data → Save
          3. Environment variables → Add variable:
            • Variable name: ADMIN_PASSWORD
            • Value: pick a strong password (24+ random chars recommended)
            • Save
          4. Go to Deployments tab → click the latest deployment menu → Retry deployment so it picks up the bindings.
          5. Refresh this page → click Sign in → paste the password above.
